# 우쭈링 표정 이미지 20종 (GitHub Pages용)

라이브러리 원본 20장을 별도 PNG 파일로 유지한 정적 사이트입니다. 기준원본/캐릭터시트, 개인 지침 텍스트는 포함하지 않았습니다.

## GitHub Pages 배포
1. 공개(Public) GitHub 저장소 `uzzuring-expressions`를 생성합니다.
2. 이 패키지의 **압축을 풀어 안의 파일과 `images` 폴더 전체**를 저장소 최상위(root)에 올립니다. ZIP 파일 자체만 올리면 웹페이지가 작동하지 않습니다.
3. 저장소 Settings > Pages > Build and deployment에서 Deploy from a branch / main / /(root)를 선택하고 저장합니다.
4. 사이트 주소 예: `https://USERNAME.github.io/uzzuring-expressions/`
5. 이미지 직접 주소 예: `https://USERNAME.github.io/uzzuring-expressions/images/02_smirk.png`

주의: 저장소가 공개라서 누구나 이미지를 볼 수 있습니다. 이 주소를 ChatGPT 답변에 매번 자동으로 렌더링하는 기능까지 보장하지는 않습니다.

파일명/표정 매핑은 `expressions.json`을 참고하세요.
